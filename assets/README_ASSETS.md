# TAKORON Taiko Game Assets v1

このZIPは、Ouchi Colon「TAKORON たいこゲーム」用の画像アセット一式です。

## 使い方

リポジトリ直下で展開すると、以下の既存ファイルを同名で上書きできます。

- assets/bg/start_bg.png
- assets/bg/game_bg.png
- assets/logo/takoron_title.png
- assets/characters/*.png
- assets/objects/taiko_drum.png
- assets/ui/*.png
- assets/effects/*.png

## 注意

- まずは動作確認用のv1アセットです。
- 背景・タイトル・キャラクター・太鼓・UI・効果画像を分離しています。
- MIKAROは手なしの画像を使用します。
- TAKORONは添付デザインに寄せた画像を使用します。
- 透明背景指定で生成したものもありますが、環境によっては白背景付きとして見える場合があります。最初の実装確認用として使い、必要なら後で透過処理します。
